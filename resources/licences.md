# WinDown — Licences et attributions

**WinDown — Version Windows JYH 2026.** Éditeur Markdown pour Windows, écrit en JavaScript.

## Œuvre d'origine : MacDown

WinDown est **inspiré de MacDown** (<https://github.com/MacDownApp/macdown>), l'éditeur Markdown libre pour macOS
créé par **Tzu-ping Chung**. WinDown reprend de MacDown le comportement, les valeurs par défaut, la structure des
menus et des raccourcis, des thèmes d'éditeur et des feuilles de style, et le texte de l'aide (adapté).
Aucun code source de MacDown n'est repris : WinDown est une réécriture. **WinDown n'est ni approuvé ni
affilié à l'auteur de MacDown.**
